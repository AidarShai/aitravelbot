# ✈️ Travel Planner Bot

AI-планировщик путешествий для Telegram. Вводишь город + даты + бюджет + настроение →
бот подбирает 3 варианта жилья, 5 мест и 3 ресторана с Google Maps ссылками.

---

## Быстрый старт

### 1. Получить токены

**Telegram Bot Token:**
1. Открой @BotFather в Telegram
2. `/newbot` → придумай имя → получи токен вида `123456:ABCdef...`

**Anthropic API Key:**
1. Зайди на console.anthropic.com
2. API Keys → Create Key → скопируй (`sk-ant-...`)
3. Бесплатных кредитов хватит на десятки планов (~$0.01 за план)

---

### 2. Запустить локально

```bash
pip install python-telegram-bot==21.5 anthropic==0.25.0

export BOT_TOKEN="токен_от_BotFather"
export ANTHROPIC_API_KEY="sk-ant-..."

python travel_bot.py
```

---

### 3. Задеплоить на Railway (постоянный хостинг, бесплатно)

1. Залей оба файла (`travel_bot.py`, `requirements.txt`) на GitHub
2. Зайди на railway.app → Login with GitHub
3. New Project → Deploy from GitHub repo → выбери репозиторий
4. Variables → добавь две переменные:
   - `BOT_TOKEN` = токен от BotFather
   - `ANTHROPIC_API_KEY` = ключ от Anthropic
5. Готово — Railway запустит бота автоматически

---

## Команды бота

| Команда | Что делает |
|---------|-----------|
| `/plan` | Начать планирование поездки |
| `/saved` | Список сохранённых мест |
| `/trips` | История всех планов |
| `/help` | Справка |

---

## Как выглядит сценарий

```
/plan
→ Куда едем?
  Лиссабон

→ Когда?
  10-17 июля

→ Бюджет на двоих?
  800 EUR на всё

→ [кнопки настроения]
  🏛 Культура и история

⏳ Подбираю план... (10-15 сек)

✅ План готов!
📍 Лиссабон · 10-17 июля

Лиссабон — идеальный выбор для культурного путешествия...
💡 Совет от местных: ходи по Алфаме рано утром...

[🏨 Жильё] [🗺 Места] [🍽 Рестораны]
[💾 Сохранить всё] [🔄 Новый план]
```

Нажимаешь `🏨 Жильё` — получаешь 3 варианта с ценами и ссылками на Google Maps.
Нажимаешь `❤️ Сохранить` — они появляются в `/saved`.

## Стоимость использования

Каждый план через Anthropic API стоит ~$0.01-0.02.
Начальные бесплатные кредиты (~$5) = 250-500 планов.
